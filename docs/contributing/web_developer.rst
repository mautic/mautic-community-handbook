Web developer
#############

Managing the Mautic websites
****************************

The Mautic Community has several web assets that require regular updates, improvements, and development of new features.

If you're a keen web developer and have experience with :xref:`WordPress`, the community welcomes your contribution.

While Hostnet hosts the main ``mautic.org`` website, the Mautic Community drives new developments and innovations.

Mautic is building a web development team in the community specifically to look after these web properties and keep the project moving forward.

Getting started
***************

The first step is to join :xref:`Mautic Community Slack` and head over to the ``#mautic-community-website`` channel. This is a public channel where the team providing "keep the lights on" support is present.

The :xref:`Mautic website repo` hosts the code for the main ``mautic.org`` site, so submit your pull requests there.

The Education Team maintains the other websites and coordinates in ``#t-education`` on Slack.

The websites that this team supports include:

* The :xref:`User Documentation` on Read the Docs
* The :xref:`Developer Docs` on Read the Docs
* The :xref:`Mautic Knowledgebase` on PHPKB
* The :xref:`Community Handbook` on Read the Docs
* The :xref:`Mauticon website` on WordPress

Except for the Knowledgebase, each site uses a GitHub repository and includes editable links at the bottom of each page.

Your first task
===============

After joining the Slack channels, ask in the channel for a task to work on. The teams don't currently maintain a specific list of tasks in Jira or GitHub.

Work in the public domain
-------------------------

Unless there's a significant reason not to, prioritize openness and transparency in the work process. Collaboration usually occurs in shared :xref:`Mautic Google Drive` or on GitHub pull requests. This ensures that if a contributor is unable to complete a task, it's easy for someone else to pick up where they left off. It also means anyone can always find previous work if needed for future re-use.

Please always ensure that you upload or push work at regular?ideally daily?intervals. Use the prefix of ``WIP-`` to indicate that the work is currently in progress.

Update regularly
----------------

Please provide regular updates on the task. If you can't complete the task, send the Team Lead a message to inform them so someone else can take it over.

Life can be unpredictable, and it's easy to take on too much at once. There's no judgment here. The team's goal is to show respect for one another by providing as much notice as possible when unable to fulfill an assigned task.
